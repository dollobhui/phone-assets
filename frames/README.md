# 票根与头像框素材

这个目录存放可复用的透明 PNG 头像框。

## 图片约定

- `ticket-frame.png`：三层叠放票根，外部与照片窗口透明，2000 × 2000 RGBA。
- 头像照片应放在透明 PNG 的**下面**作为单独图片层，票根保持最上层。
- 保持票根素材原始比例，使用 `object-fit: contain`，勿裁切或额外旋转票根。
- 如果使用 jsDelivr 并更新同名图片，缓存可能延迟，建议改文件名或使用版本固定的 URL。
